### ✅ 신규 기능 & 기능 개선

**영업씬**
- 손님 입/퇴장 시 위아래로 반동주면서 이동하는 기능 추가
- 세션 타이머 0이 되면 들어오던 입장하던 손님들까지 입장하고 퇴장까지 완료 했을때 마감처리 하던 부분 수정
  > 세션 타이머 0이 되면 진입 중인 손님 반대로 퇴장 처리
  > 마지막 손님의 주문 팝업이 사라지고 퇴장하려는 타이밍에 마감 패널 오픈
- 초기 임시로 사용하던 조리대 상태별 이미지 전체 최종 픽스된 조리대 이미지로 교체
- 서빙 판정 범위를 확대하여 영업 중 편의성 개선
- 손님 인내심 게이지 변화에 따른 손님 상태 이미지 교체 / 기본, 지침, 화남, 즐거움 4종

- 튜토리얼 가이드 (첫 플레이) 신규 추가

- 손님별 타입 추가. 타입에 따라 인내심 게이지가 달라지도록 수정
  > 일반 / 느긋함 / 시간없음 / 성격급함
- 레시피에 개별 판매가격 추가, 개별 조리시간 추가

### ✅ 게임 규칙 수정
* 고정 규칙: 트럭등급이 상승하면 단골손님과 레시피가 각 1개씩 오픈되고, 트럭등급 4부터는 단골손님이 좋아하는 전용레시피가 등장합니다. 전용레시피는 마지막 재료에서 분기가 일어나며 단골 손님이 주문했을때는 전용 재료를 넣어야 하고, 일반 손님이 주문했을때는 기본 재료를 넣어야합니다. 그리고 단골손님마다 교유의 유물이라는 잡화템을 일정 확률로 두고갑니다.

1. 재료 투입 순서 규칙 제거 → 재료 종류만 맞으면 성공하도록 수정
2. 메뉴 종류 총 3종으로 개편
  > 기본 메뉴(트럭등급 1에서 오픈, 총 3개): 일반 재료 3개
  > 일반 메뉴(트럭등급 2, 3에서 오픈): 일반 재료 4개
  > 전용 메뉴(트럭등급 4부터 오픈): 일반 재료 3개 + 마지막 재료 1개(분기)
3. 플레이어가 조작에 익숙해지는 시간을 가질수 있도록 트럭등급 3까지 일반재료로 플레이 후 트럭등급 4부터 전용레시피가 등장하도록 수정. But, 트럭등급 2부터 등장하는 손님은 단골손님으로 유물은 그대로 획득할 수 있도록 유지
5. 손님 주문 팝업이 나올때 힌트 문구가 머리위에 메뉴별 3~4개 랜덤으로 출력되는 기능 추가, 5초 간격으로 순환

### ✅ 밸런스 설정 (전체 적용 완료)

- 세션 길이: 120초
- 손님 등장 간격: 조리대 레벨에 따라 손님 등장간격이 빨라지도록 조절
- 조리 시간
| 메뉴 종류 | 해금 등급 | 조리 시간 |
|---|---|---|
| 기본 메뉴 | 등급 1 | 4.5초 |
| 일반 메뉴 | 등급 2~3 | 5.5초 |
| 초반 전용 메뉴 | 등급 4~5 | 6초 |
| 중반 전용 메뉴 | 등급 6~8 | 7초 |
| 후반 전용 메뉴 | 등급 9~10 | 8초 |

- 손님 인내심: 기본 28초, 타입별 가중치 적용
| 타입 | 배율 |
|---|---|

- 음식 상하는 시간: 15초
- 전용 손님이 전용 메뉴를 주문할 확률: 45%
- 서빙 EXP: 성공 서빙 1회 = EXP +1 (메뉴·손님 종류 무관, 전용 성공 추가 없음)

- 유물 드롭 확률: 전용 손님 만족 시 15%

### 현재 플레이 가능한 범위
> 타이틀 → 로비 → 영업 시작 → 튜토리얼(첫 플레이) → 손님 등장/주문 → 재료 투입 및 조리 → 완성 음식 드래그 서빙 → 골드·경험치 적립 → 세션 마감 → 트럭 등급 상승 및 해금 확인 → 로비 도감·업그레이드 → 반복
